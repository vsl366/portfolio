# VSL

Personal portfolio of Vishal S. Plain HTML, CSS and JavaScript with no build step.

## Run it

Open `index.html` in a browser, or serve the folder with any static server.

## Pages

- `index.html` is the main site: moonlit canyon, particle story, three heads, work, journey and contact.
- `art.html` and `piano.html` are the art and piano pages. The piano is playable.
- `play.html` is Team 2's Pac-Man from SSN CSE, ported from C to JavaScript.

## Editing content

All text, projects and links live in `js/data.js`.

See `CREDITS.md` for fonts, libraries and assets.
